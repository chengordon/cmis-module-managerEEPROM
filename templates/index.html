⚠ Write is irreversible. It overwrites the EEPROM contents — never point it at a live CMIS optical module. Leave 确认 / Confirm unticked for one-click programming (no dialog, no toast); tick it to require the 确定 / 取消 confirmation. Unlike Raw Registers, neither Read nor Write touches byte 0x7F as a page-select register: on a plain EEPROM that byte is data.

Read — 24C02 is one 256-byte device at 8-bit address 0xA0 (8-byte pages), 24C04 is two 256-byte blocks at 0xA0–0xA2, and 24C08 is four at 0xA0–0xA6 (both 16-byte pages). Addresses are shown as 8-bit (7-bit slave address left-shifted by one, e.g. 0x50 → 0xA0); the tool converts back to 7-bit for the driver. A dump covering 0x000–0x00B decodes the chip's current Serial Number. On a CMIS optical module read only the first 256 bytes: 0xA2/0xA4/0xA6 do not exist there.
Read → Write — a successful Read makes the content-area dump the image to program, enables the Write button without any .bin file, and copies the 12 ASCII bytes at 0x000–0x00B into the Serial Number field. This supports "read a golden part → program the next boards" directly. A failed Read keeps the previous image; Clear and disconnect discard a chip readback.
Select file — the chosen .bin is immediately shown in the content area below, and its first 12 ASCII bytes (0x000–0x00B) are loaded into the Serial Number field, e.g. CAD211193882. Whichever came last — Read or file — is what Write programs.
Write — with 确认 / Confirm unticked (default), a Write click programs the content area immediately: no dialog, no toast, no extra click. Tick it only when you want a confirmation step; the in-page dialog then sits just above the Write button with 确定 / 取消 in its last row, so the mouse barely moves (a browser-native confirm() is pinned to the top of the window and cannot be moved). 确定 is focused, so Enter confirms; Esc / 取消 / the backdrop abort without writing. Write then replaces bytes 0x000–0x00B with those 12 ASCII characters, and programs the image in page-sized pieces (8 B / 16 B), split again at each 256-byte block boundary. Every page is followed by a 10 ms write-cycle wait; Verify re-reads each page and reports mismatches. The Serial Number is a 12-character printable ASCII string (e.g. CAD211193882) kept in this browser. With 自动递增 / Auto-increment ticked (default), the digit run selected by 递增位置 / Increment at increments by 1 on every Write that is actually sent; letters never change, so CAA2127891EB → CAA2127892EB. Leave 递增位置 empty to auto-detect the last digit run, or enter a 0-based inclusive range like 3-9 to pin exactly which characters may change. Untick it and the S/N stays put across writes — advance it only with Next. Reading the chip or selecting a .bin reloads the value from the content area's 0x000–0x00B automatically. The Mock demo backend rewrites dynamic registers (e.g. 0x03, 0x0E–0x0F) on every read, so Verify can report false mismatches there; real 24C02/24C04/24C08 hardware is not affected.
